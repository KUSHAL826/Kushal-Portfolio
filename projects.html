Livestock Dual Node Monitoring System

Problem: Livestock diseases are often detected too late because farmers cannot continuously observe the health and behavior of each animal. This leads to preventable losses and reduced productivity.

Solution: I designed and developed a dual-node IoT-based monitoring system. The first node is an ear tag embedded with a temperature sensor and microcontroller to monitor vital body parameters. The second node is a smart collar built with an ESP32 and an accelerometer to track movement, activity, and behavioral patterns. Both nodes continuously collect data and transmit it to a web platform.

Outcome: On the platform, the sensor data is combined with real-time analytics to flag abnormal temperature or inactivity, enabling early disease detection and efficient livestock management. The system is designed to be low-cost and scalable for rural usage. This work is the basis of a filed patent (App No. 202641092055) and a published research paper.

Tech: IoT, ESP32, Temperature & Accelerometer Sensors, Arduino IDE, Web Analytics  |  Timeline: 06/2025 – 06/2026

Smart Farming Platform — Crop Price Prediction

Problem: Farmers frequently choose crops without knowing how market prices will move, which leads to unstable income and losses when supply exceeds demand.

Solution: I built a full-stack smart farming web application that uses machine learning models to predict future market prices for various crops. The platform takes in land details, resource availability, historical price trends, and market demand, then processes this data through trained models to forecast the most profitable options.

Outcome: The application turns raw agricultural data into clear, actionable recommendations, helping farmers make informed decisions, reduce risk, and improve income stability.

Tech: Python, Machine Learning, Full-Stack Web, MySQL  |  Timeline: 05/2025

Smart Irrigation System (IoT + AI)

Problem: Traditional irrigation wastes large amounts of water because it is done on fixed schedules rather than actual field conditions.

Solution: I engineered an automatic irrigation system that integrates IoT hardware devices with AI-based decision-making algorithms. Soil moisture and environmental sensors continuously feed live data into an intelligent controller, which decides exactly when and how much to irrigate.

Outcome: The system automates the irrigation cycle, significantly reduces water wastage, and improves crop yield through data-driven control instead of guesswork.

Tech: IoT, AI/ML, Soil Moisture Sensors, Arduino IDE  |  Timeline: 09/2025

Student ERP System

Problem: Managing student information, academic records, and administrative tasks manually is slow, error-prone, and hard to keep consistent across departments.

Solution: I developed a Student ERP (Enterprise Resource Planning) system to centralize and automate student-related operations. The system handles student records, academic details, and administrative data through a structured database with a clean, user-friendly interface for managing and retrieving information.

Outcome: The ERP streamlines data management, reduces manual effort and errors, and provides quick, organized access to student information, demonstrating my full-stack and database design skills.

Tech: Full-Stack Web, MySQL, DBMS  |  Focus: Data Management & Automation
