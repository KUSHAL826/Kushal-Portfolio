Smart Health Monitoring Ear Tags

This project addresses the challenge of continuous health monitoring in livestock, where early disease detection is often difficult and delayed. The main objective is to build a smart system that tracks vital parameters like body temperature and activity levels in real time. It is a combination of hardware and software, where the hardware includes an ear tag embedded with a temperature sensor, microcontroller, and battery. Additionally, a smart collar with ESP32, accelerometer sensor, and battery is used to track movement and behavior. The collected data is transmitted to a web-based platform for monitoring and analysis by farmers. This enables efficient livestock management, reduces losses, and improves productivity. The system is designed to be low-cost and scalable for rural usage.

Status: Market verification of sensors is completed with positive results. Currently working on integrating all components and building the full working prototype.

Smart Farming

This project aims to solve the issue of crop price instability and poor crop selection faced by farmers. The objective is to provide data-driven crop recommendations based on land details, resource availability, and market demand. The system takes inputs such as soil type, water availability, land size, and seasonal conditions. It then compares this data with demand information collected from government sources and market trends. Based on this analysis, the platform suggests the most profitable and suitable crops for cultivation. This helps farmers make informed decisions, reduce risks, and improve income stability. The solution focuses on bridging the gap between agriculture and data intelligence.

Status: Website development is completed successfully. Currently in the stage of market validation and real-world testing with farmers.

GNA Foods

GNA Foods is a local entrepreneurial initiative started in my native place to produce and deliver homemade masala products. The goal is to promote authentic, high-quality food products while supporting local business and employment. The initiative focuses on preparing fresh and hygienic masala items and delivering them directly to customers’ doorsteps. We have obtained government food certification and legal permissions to operate the business. As part of this project, I designed and developed the official website to create an online presence. The website helps in showcasing products and enabling easy customer interaction. This project combines technical skills with real-world business implementation.

Status: Business setup is completed and ready for implementation. Website is live and prepared for handling orders and scaling operations.

Organic E-commerce Platform

This project is an e-commerce platform designed to promote and sell organic products online. The frontend is developed using HTML and CSS to create a clean and user-friendly interface. The backend is built using PHP, with MySQL used for database storage and management. The system includes features like user login, product listing, cart functionality, and order management. Apache server is used to run the application locally and during development. The platform demonstrates full-stack development skills and real-world application design. It focuses on providing a smooth and secure online shopping experience.

Status: Platform is deployed on InfinityFree with database integration. Currently exploring possibilities to implement and scale it for real-time usage.
