Patent: Livestock Dual Node Monitoring System

Invented an innovative dual-node IoT system for livestock health and environmental tracking, integrating sensor data with real-time analytics. The system combines an ear-tag node and a smart-collar node to continuously monitor vital parameters and behavior, enabling early disease detection and efficient livestock management.
