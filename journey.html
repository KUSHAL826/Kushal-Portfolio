My journey in technology began with a strong curiosity to understand how systems work and how problems can be solved logically. Learning Data Structures and Algorithms further strengthened my ability to approach problems efficiently and design optimized solutions.

Building Through Web Development

As I progressed, I developed a strong interest in building complete systems, which led me to focus on web development as a practical medium for implementation. I worked with HTML, CSS, and basic JavaScript to design user interfaces, and used PHP and MySQL for backend development and data management.

Through this, I gained hands-on experience in building full-stack applications, managing databases, and deploying projects using Apache and MySQL servers. This phase helped me understand how real-world applications function end-to-end, from frontend interaction to backend processing.
