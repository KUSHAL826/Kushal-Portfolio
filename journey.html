My Journey

A journey focused on building practical solutions, strengthening fundamentals, and continuously learning through real-world implementation.

Foundation & Problem Solving

My journey in technology began with a strong curiosity to understand how systems work and how problems can be solved logically. I started with C programming, which helped me build a solid foundation in problem solving and structured thinking. Learning Data Structures and Algorithms further strengthened my ability to approach problems efficiently and design optimized solutions.

Alongside this, I explored Object-Oriented Programming using C++, which helped me understand how to design modular and scalable systems. I also developed a strong base in core computer science concepts such as Operating Systems and Database Management Systems, which are essential for building reliable and efficient applications.

Building Systems Through Web & IoT

As I progressed, I developed a strong interest in building complete, working systems. I worked with HTML, CSS, and Python along with MySQL for backend logic and data management, and combined this with IoT and hardware integration using the ESP32 and various sensors.

This hands-on experience helped me understand how real-world applications function end-to-end, from sensors and data collection to processing, storage, and user-facing platforms.

Projects & Real-World Applications

  • Livestock Dual Node Monitoring System: A dual-node IoT system (ear tag + smart collar) that monitors livestock health and environmental conditions in real time. This work became a filed patent (App No. 202641092055) and a published research paper.
  • Smart Farming Platform — Crop Price Prediction: A full-stack web application using machine learning models to predict future crop market prices, helping farmers make informed, profitable decisions.
  • Smart Irrigation System (IoT + AI): An automatic irrigation system that integrates IoT hardware with AI-based decision-making to optimize water usage and improve crop yield.
  • Student ERP System: A full-stack ERP application that centralizes and automates student records and administrative tasks through a structured database and a clean management interface.

Exploring Generative AI (Started August)

In August, I began exploring Generative AI from the very basics and progressed step by step. I started with prompt engineering, learning how to craft effective prompts, and then moved on to working with API keys to connect with language models.

From there I practiced text generation and built my first chatbot. I then learned to produce structured output in JSON so responses could be used reliably by applications. Next I explored embeddings and vectors, which led me into Retrieval-Augmented Generation (RAG) and cosine similarity for finding relevant information.

Building on these fundamentals, I started working with LangChain to orchestrate AI workflows and Streamlit to build simple, interactive interfaces for my AI experiments. I am continuing to strengthen these concepts through consistent, hands-on practice.
